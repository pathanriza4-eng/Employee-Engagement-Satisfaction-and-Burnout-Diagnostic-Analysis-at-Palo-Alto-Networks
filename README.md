# Employee Engagement, Satisfaction & Burnout Diagnostic Analysis

This project analyzes employee engagement, satisfaction, burnout risk, work-life balance, and attrition using HR analytics. It identifies high-risk employee groups and key factors affecting engagement.

## Objectives

* Measure overall employee engagement.
* Identify burnout-prone employees.
* Analyze overtime and work-life balance.
* Study engagement by role, department, and career stage.
* Compare engagement with attrition.
* Provide actionable HR recommendations.

## Technologies

* Python
* Pandas & NumPy
* Matplotlib & Seaborn
* Streamlit
* Jupyter Notebook / Google Colab

## Dashboard

The Streamlit dashboard provides engagement health, burnout risk, role & career analysis, and manager action insights with interactive filters.

## Dataset

The dataset includes employee demographics, job details, satisfaction scores, compensation, workload, career history, and attrition information.

## Outcome

The project helps HR teams move from reactive attrition analysis to proactive employee well-being and retention strategies.
